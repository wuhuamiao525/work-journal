# 每日工作日记系统

一个简洁、高效的本地工作日记管理工具 🚀

## ✨ 功能特性

### 1. 会议安排 📅
- 记录会议名称、时间、地点
- 标记会议完成状态
- 支持新建、编辑、删除

### 2. 项目人员安排 👥
- **三个分类**: 进行中/已交付/已验收
- **14个字段**: 编号、项目名称、交付节点、人员配置等
- **Tab 切换**: 方便查看不同状态的项目

### 3. 项目待办 ✅
- 创建项目条目
- 每个项目可添加多个任务
- 任务完成状态管理

### 4. 工作日记 📝
- 大文本框记录每日工作
- 自动保存（1秒防抖）

### 5. 自动同步 🔄
- **工作日早上9点**自动复制昨日未完成内容
- 自动跳过周末
- 智能过滤已完成项

## 🚀 快速开始

### 方法 1: 使用启动脚本（推荐）

直接双击运行：`START.bat`

### 方法 2: 手动启动

```bash
cd d:\code\work-journal
npm install
npm run dev
```

访问: `http://localhost:5173`

## 💾 数据存储

- 所有数据存储在浏览器 localStorage
- 刷新页面数据不会丢失
- 按日期组织：workJournal_YYYY-MM-DD

## 🛠️ 技术栈

- React 18 + TypeScript
- Vite 7
- Ant Design 5
- moment.js

## 📖 使用说明

1. 选择日期查看不同日期的工作日记
2. 所有修改1秒后自动保存
3. 工作日早上9点后首次打开自动同步昨日数据
