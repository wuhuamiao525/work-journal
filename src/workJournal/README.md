# 每日工作日记系统

## 功能概述

这是一个本地运行的每日工作日记管理系统，用于跟踪和管理日常工作内容。

### 主要功能

1. **会议安排管理**
   - 记录会议名称、时间、地点
   - 支持标记会议完成状态
   - 支持新建、编辑、删除会议

2. **交付项目人员安排**
   - 三个Tab：进行中的项目、已交付的项目、已验收项目
   - 每个项目包含14个字段（编号、项目名称、交付节点、人员配置等）
   - 支持项目的新建、编辑、删除、状态流转

3. **交付项目待办**
   - 项目条目下可创建多个任务
   - 支持任务的新建、删除、状态修改
   - 树形结构展示（项目→任务）

4. **工作日记**
   - 大文本框记录每日工作内容
   - 自动保存，无需手动操作

5. **自动同步**
   - 工作日早上9点自动复制昨日未完成内容
   - 自动跳过周末，从上个工作日复制
   - 已完成的会议和任务不会被复制
   - 日记内容不会被复制

## 使用方法

### 访问页面

启动项目后，访问：`http://localhost:8000/workJournal/index`

### 基本操作

1. **选择日期**：点击页面顶部的日期选择器，可以查看和编辑不同日期的工作日记

2. **折叠面板**：四个功能模块都在可折叠面板中，可以根据需要展开或折叠

3. **自动保存**：所有修改都会在1秒后自动保存到localStorage，无需手动保存

4. **数据持久化**：所有数据存储在浏览器的localStorage中，刷新页面不会丢失

### 自动同步功能

系统会在以下条件下自动同步：
- 当前是工作日（周一到周五）
- 时间超过早上9:00
- 当日数据不存在

同步规则：
- 会议：只复制未完成的会议
- 项目：全部复制（三个Tab中的所有项目）
- 待办：只复制未完成的任务，移除没有任务的项目
- 日记：不复制

### 跨周末使用

- 周一早上会自动复制上周五的数据
- 周六、周日不会触发自动同步
- 可以手动查看和编辑周末的记录

## 技术实现

### 文件结构

```
src/pages/workJournal/
├── index.tsx                    # 主页面
├── index.less                   # 样式
├── types.ts                     # TypeScript 类型定义
├── README.md                    # 说明文档
├── services/
│   ├── storage.ts              # localStorage 封装
│   └── autoSync.ts             # 自动同步逻辑
├── components/
│   ├── MeetingSection.tsx      # 会议管理组件
│   ├── ProjectSection.tsx      # 项目管理组件
│   ├── TodoSection.tsx         # 待办管理组件
│   └── DiarySection.tsx        # 日记组件
└── modals/
    ├── MeetingModal.tsx        # 会议新建/编辑弹窗
    ├── ProjectModal.tsx        # 项目新建/编辑弹窗
    └── TodoModal.tsx           # 待办新建弹窗
```

### 数据存储

- **存储位置**：浏览器 localStorage
- **存储键名**：`workJournal_YYYY-MM-DD`（例如：`workJournal_2026-02-26`）
- **数据格式**：JSON 字符串

### 技术栈

- **框架**：Umi 3 + React 17
- **UI组件**：Ant Design Pro
- **状态管理**：React Hooks
- **日期处理**：moment.js
- **本地存储**：localStorage

## 注意事项

1. **浏览器兼容性**：需要支持localStorage的现代浏览器

2. **存储空间**：localStorage限制为5-10MB，估算可存储500+天的数据

3. **数据备份**：建议定期导出数据进行备份（可扩展功能）

4. **清除数据**：可以通过浏览器开发者工具清除localStorage数据

5. **多设备同步**：当前版本不支持多设备同步，数据仅存储在本地浏览器

## 问题排查

### 数据没有保存

- 检查浏览器是否允许localStorage
- 检查是否超出存储空间限制
- 检查浏览器控制台是否有错误信息

### 自动同步没有触发

- 确认当前是工作日（周一到周五）
- 确认时间超过9:00
- 确认当日数据尚未创建
- 检查浏览器控制台是否有错误信息

### 页面无法访问

- 确认项目已正确启动
- 确认路由配置正确
- 检查浏览器控制台是否有编译错误
